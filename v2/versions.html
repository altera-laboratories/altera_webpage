In the workshop

Four themes off one source file

v2/_site.html is where the design is still moving. It carries no forked copies: one file, one set of tokens, and a theme layer that swaps their values under html[data-theme]. Paper is the shipped identity, Meridian is the rebrand finalist.

Where it came from

The three identity studies, July 2026

Before the paper page existed there were three full-page directions built to be argued over. B won and became the Reading Room. A and C are kept because the reasons they lost are still the reasons the current page looks the way it does.

A · Deep Ink Atelier

Dark ground kept, craft added on top. Closest to v1, which was the problem: it did not change the first impression enough.

Not chosen a-deep-ink-atelier

B · The Reading Room

The winner. Paper ground, serif display, blue reserved for data. Everything shipped since is a refinement of this panel.

Became v2 b-reading-room

C · Field Notebook

Graph paper and lab notation on a dark ground. Strong character, but it read as a tool for researchers rather than for a class.

Not chosen c-field-notebook
